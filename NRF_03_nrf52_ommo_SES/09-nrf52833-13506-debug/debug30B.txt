0. 关于 event task的讲解：
   pending  --  51单片机的flag
   process  --  51单片机的回调函数
   注册     --  函数指针赋值

1. 正确的 pending 实现：

   bool my_pending(void *ctx) 
      return work_ready;   // 只读，不改状态

   ---

   void my_process(void *ctx) 
       if (work_ready)    
           work_ready = false;   // ★ 在 process 里清标志，不在 pending 里清 ★
           // 干活...


2. main_loop_only = true 的理解
  大家依次进屋换衣服。 有两个人是小偷，可能偷衣服，必须让它们排队等候，等别人出来后才让它们进去换衣服



---------

execute_once()	遍历一次，pending 为 true 的任务执行一次
execute_forever()	死循环，不断执行 execute_once()
execute_once_with_sleep()	执行一轮，没活就睡觉（__WFI）
execute_forever_with_sleep()	死循环，每轮干完活检查一次，没活就睡觉
