
STATE_RX_TIMEOUT流程：

[1-Wire 通信中]
    ↓
从机预期收到数据（timestamp 包 / 数据包）
    ↓
设置了 TIMER0 CC2 超时阈值（540us 或 4ms）
    ↓
┌─────────────────────────────────────────────────────────────┐
│ 正常情况                                                   │
│ 在超时前收到数据 → 清除 CC2 事件标志 → 正常处理           │
└─────────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────────┐
│ 异常情况：超时了！                                         │
│ TIMER0 计数到 CC2 阈值                                     │
│    ↓                                                       │
│ 触发 TIMER_EVENT_COMPARE2 中断                             │
│    ↓                                                       │
| timer_event_handler(TIMER_EVENT_RX_TIMEOUT)                │
|    ↓                                                       |
| state = STATE_RX_TIMEOUT                                   |
| uarte_resource->rx_abort()                                 |
└─────────────────────────────────────────────────────────────┘
    ↓
[UARTE 接收被中止] → 触发 ENDRX 或 ERROR 事件
    ↓
on_comms_uarte_event() 中检测到 RX_DONE（被中止）
    ↓
检测到 state == STATE_RX_TIMEOUT
    ↓
initiate_handshake_now(TRACE_1WIRE_DISCONNECTED_RX_TIMEOUT)   ★ 就是这里 ★
