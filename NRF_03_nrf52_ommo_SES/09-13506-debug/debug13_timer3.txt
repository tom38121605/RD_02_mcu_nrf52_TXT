
TIMER3 是系统主时钟 

    产生 1ms 采样事件（触发传感器采集）  //CC0
    4ms 同步事件（与主机对时）           //CC1



[系统初始化]
    ↓
timestamp_init_with_internal_sample_event()
    ↓
初始化 TIMER3 → 设置默认配置 + 中断
    ↓
申请两个 CC 通道：
├─ sample_event_compare_channel   （~1ms 采样事件）
└─ timestamp_synch_event_compare_channel（~4ms 同步事件）
    ↓
读取当前 TIMER3 值，计算第一次触发时间
sample_event_trigger_value = 当前值 + 15984*4
    ↓
设置第一次采样事件触发
nrfx_timer_compare(CC_sampe, sample_event_trigger_value)
    ↓
┌───────────────────────────┐
│                  循环运行                            │
│                                                     │
│  TIMER3 计数到 CC_sample → 触发中断                 │
│       ↓                                             │
│  timestamp_timer_event_handler()                    │
│       ↓                                             │
│  1. 计算下一次采样时间 + 15984                      │
│  2. 设置下一次采样触发                              │
│  3. 如果到同步事件（每4次）→ 触发同步               │
│       ↓                                             │
│  [采样事件] → 调用 sample_set_ready()              │
│       → 采集传感器数据                              │
│                                                     │
│  [同步事件] → 调用 timestamp_synch_execute_functions│
│       → 发送同步包（UART/1-Wire/ESB）              │
│                                                     │
│  [外部同步包到达] → timestamp_synch_recieved()     │
│       → 校正 sample_event_trigger_value             │
│       → 重新设置下一次采样时间                      │
│       → 重置同步丢失看门狗（RTC2）                 │
└───────────────────────────┘




事件	触发频率	函数	作用
采样中断	~1ms	timestamp_timer_event_handler	计算下次采样时间，触发传感器采集
采样回调	~1ms	sample_set_ready()	采集传感器数据，打包发送
同步事件	~4ms	timestamp_synch_execute_functions[]	发送同步包给主机
同步校正	每次收到同步包	timestamp_synch_recieved()	校正本地时钟偏移，重置 RTC2

//如果已收到同步包，则清0同步接收标志。如未收到同步包，则同步包次数+1
timestamp_on_synch_event( )
 
    //Keep track of timestamp events since last synch

    //判断 是否已收到同步包
    if( timestamp_synch_received_msk&0x02 )     //如果已收到同步包
 
        timestamp_synch_consequtive_misses = 0;  //把同步包丢失次数清0

        //原子操作，设置timestamp_synch_received_msk的bit2=0，把同步接收标志恢复到初始状态
        __atomic_and_fetch(&timestamp_synch_received_msk, ~0x02, __ATOMIC_SEQ_CST);
    
    else 
        timestamp_synch_consequtive_misses++;   //同步包丢失次数 +1

//差值回卷修正
calculate_wrapped_delta(  first,  second,   period )

      delta = first - second;

      if( delta < - (period>>1) ) //UINT32_MAX
          delta += period;

      if( delta >  (period>>1) )
          delta -= period;

      return delta;
