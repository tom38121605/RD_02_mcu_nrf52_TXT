timer3： timer_timestamp



[TIMER3 硬件启动，16MHz 计数器自由狂奔]
       │
       │
       ├─► [CC0 比较匹配 (每 1ms 触发)]
       │     │
       │     ├─ (硬件 PPI) ──► 触发 TIMER0 TASKS_START (开始采 X/Y/Z)
       │     └─ (CPU 中断) ──► timestamp_timer_event_handler()
       │                         ├─ 累加下一拍时间
       │                         ├─ 重写 CC0 寄存器 (设置下一次 1ms 门槛)
       │                         └─ 执行 sample_event_callbacks 回调
       │
       │
       ├─► [CC1 比较匹配 (每 4ms 触发，与 CC0 对齐)]
       │     │
       │     ├─ (硬件 PPI) ──► 触发 UARTE TASKS_STARTTX (发送同步回包)
       │     └─ (CPU 中断) ──► 计算下一个 4ms 的 CC1 门槛并写入
       │
       │
       └─► [外部信号硬件触发 (例如 UARTE 收到基站同步包)]
             │
             ├─ (纯硬件 PPI) ──► 瞬间触发 CC2 (或 CC3/4/5) 的 CAPTURE 任务
             │                    (把当前计数锁存为 local_ts，用于计算偏差)
             │
             └─ (触发 UARTE 软件中断)
                   │
                   ▼
             解析出基站时间 (bs_ts)
             调用 timestamp_synch_recieved(bs_ts, local_ts)
                   │
                   ├─ 计算时间差 offset
                   ├─ 强行重写 CC0 门槛 (拨正下一轮采样节拍)
                   └─ 强行重写 CC1 门槛 (拨正下一轮同步节拍)



极简总结：
CC0 和 CC1 是“固定发令枪”，分别管 1ms 采样和 4ms 同步。

CC2 到 CC5 是“动态秒表”，基站来信号了，就随便抓一个秒表去拍下当前时间。

四、 总结视图（一句话串联）

初始化阶段：main() 调起 timestamp_init_...() 启动 TIMER3，再通过 timestamp_add_task_on_sample_event() 把 TIMER3 的 Event 连到 TIMER0 的 Task。

运行阶段：TIMER3 硬件每 1ms 直接通过 PPI 踹醒 TIMER0；一旦产生中断，进入 timestamp_timer_event_handler() 设置下一次阈值。

同步阶段：UARTE 收到信号后，硬件 PPI 让 TIMER3 抓取瞬间值，软件通过 timestamp_synch_recieved() 计算偏移，校准 TIMER3 的未来轨迹。

timestamp_on_synch_event( )
 
    //Keep track of timestamp events since last synch

    //判断 是否已收到同步包
    if( timestamp_synch_received_msk&0x02 )     //如果已收到同步包
 
        timestamp_synch_consequtive_misses = 0;  //把同步包丢失次数清0

        //原子操作，设置timestamp_synch_received_msk的bit2=0，把同步接收标志恢复到初始状态
        __atomic_and_fetch(&timestamp_synch_received_msk, ~0x02, __ATOMIC_SEQ_CST);
    
    else 
        timestamp_synch_consequtive_misses++;   //同步包丢失次数 +1

//差值回卷修正

参数: x,  y,  12    //以手表12个点的刻度来举例
calculate_wrapped_delta(  first,  second,   period )

      delta = first - second;

      if( delta < - (period>>1) ) //UINT32_MAX
          delta += period;

      if( delta >  (period>>1) )
          delta -= period;

      return delta;
